Drop a Unicode TTF or OTF here to export non-Latin text as real vector glyphs.

Without a font, Arabic and other non-WinAnsi text still renders on screen but is
skipped during export, and the server logs a warning saying so.

Any single .ttf or .otf works. Noto Sans Arabic is a good default:
https://fonts.google.com/noto/specimen/Noto+Sans+Arabic
